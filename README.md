# insurance-supervision-analysis
A repository that contains code towards generation of a report that identifies priority firms for supervision resource allocation.

## Data

Note: It is assumed that the raw data is located in the root of the project repository.

Cleaned data will be stored in the data/cleaned_results

## Report

The report is located in the folder marked "report", along with any plots necessary.

## Notebook

The `analysis.ipynb` notebook contains code to clean and analyse the given data.

Code and libraries were tested with Python=3.12.
